# Sample output

Reports generated by running the validator against the six provided samples.
Each folder holds `report.json` (the structured result) and `report.md` (the same
result for a human).

Regenerate any time — the pipeline is deterministic, so the output is byte-identical:

```bash
for f in "CHN Generated Samples"/*.pdf; do
  python -m pdfvalidator validate "$f" --output-dir sample-output
done
```

## Reading the numbers

- **Rules violated** counts distinct rules with at least one confident violation, not
  individual findings.
- **Needs review** is what the agent deliberately refuses to judge: where a link
  goes, or a logo with no licence reference.
- A `LOGO-LICENSE` finding on sample 06 is *compliance*, not a violation, so it does
  not count toward the total and appears under its own heading.

## Why every sample fails

Each one reuses the mandated disclaimer wording (`CHN makes no warranties…`) or the
`CHN` short form without ever introducing `Contoso Health Network® (CHN®)`. Under a
literal reading of CHN-1 that is a violation, and it is a realistic failure mode for
reused boilerplate rather than a parsing artifact. Sample 01 is the exception — it
carries the full first-mention form in its title, and its only violation is the
genuinely incomplete citation.
